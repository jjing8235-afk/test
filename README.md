# NVWA 液态玻璃

**当前测试版本：2.0.10-test.27（2026-11-23）· Android 超长气泡恢复壁纸模糊**

- Android 超长消息的新款气泡改用最多一屏高的外层模糊；从楼层上部滚动到底部时，壁纸仍有玻璃模糊效果。
- 内层仍不加底色；超长楼层继续跳过 SVG 折射、额外的整楼内层模糊和高光遮罩。经典气泡、普通双层气泡和内嵌状态栏原有行为不变。
- 隔离 SillyTavern 中以相同底色对比有／无滤镜的截图像素，覆盖 Android 窄屏、兼容模式、展开宽度和 TT 模拟；原楼层仍待真机复测。

### 延续 2.0.10-test.26 的长消息布局

- Android 长消息触发性能保护时，符合条件的楼层仍显示新款高顶、无边圆头像和双层边框。保护期间跳过额外的内层模糊和整条消息的高光遮罩，回到正常长度后恢复。
- 包在容器中且带自定义字色的正文，也可和内嵌状态栏一起使用双层外框。纯自绘卡、固定浮窗和作者自定义外框继续走原来的保护路径。
- 已在隔离 SillyTavern 中验证 Android 浏览器与 TT WebView 模拟、长短切换和状态栏交互；原卡与手机真机仍待复测。

### 延续 2.0.10-test.25 的双层玻璃外观与设置

- 名片式双层气泡拉高外层留白、加大圆角和无边圆头像，内外框高光沿边缘延展。按钮仍在正文上方，正文排版由字体工坊控制。
- 在「玻璃设置 → 界面布局 → 聊天消息」切换经典气泡或双层玻璃，默认仍为经典。双层外框跟随上下栏；内层不加底色，可在「阅读文字 → 背景与可读性」独立调整模糊（0–16 px，默认 3.5 px）。两套设置各自保存。
- 普通正文搭配留在消息内的 HTML 状态栏或有占位容器的 iframe，可使用双层外框，保留状态栏自身配色、折叠和按钮。固定浮窗、作者自定义外框和 Android 超长消息保护沿用原路径。
- 已在桌面 Edge 的隔离 SillyTavern 覆盖桌面、窄聊天栏、320 px 视口及状态栏夹具，未验收用户原卡或手机真机。

修复手机上「左右留白」只在左侧生效的问题；正文标记两边使用同样的内距，限制段宽后仍居中。保留已有排版设置，不用重设。

手机酒馆（ST）和手机 TT（TauriTavern）使用同一个测试安装地址。此版同步了长聊天的消息挂载、卡片扫描与滚动减负，不降低可见区域的玻璃材质档位；保留 Android 超长消息保护、折叠屏占位和预设自带配色。字体工坊保留四套预设，选中后行距和留白默认跟随风格；可单独设置正文和对白的字形及标记。

已在独立 SillyTavern 1.18.0 中用 Android 浏览器与 TT WebView 环境模拟复查滚动、折叠屏尺寸、超长消息和输入区，另用桌面 WebKit 复查 iPhone 布局。模拟结果不等于手机真机的帧率或屏闪验收。

## 2.0 带来了什么

- **映卿、漾卿、澄卿**：三种玻璃路径，材质与预设分组展示，既有调节继续兼容。
- **青瓷、栖暖、笺月、晴笺**：四款阅读风格，配合字号、行距、缩进及消息内阅读滤镜。
- **御风性能引擎 / 棱光折射引擎**：高楼层拖动更跟手，输入区菜单和快捷回复更利落，通透玻璃继续保留细致弧面与反光层次。
- **更清楚的设置工作台**：外观与材质、界面布局、阅读文字、高级与兼容分开组织；“我的外观”支持保存、恢复与撤销本次恢复。
- **更顺手的操作**：顶栏一个折叠入口，最多自选两个常用图标放在左侧；图标选板、胶囊滑块与共享数值浮标统一呈现。
- **高透与可读性并存**：图标随局部背景调整深浅，柔光滤镜限定在消息背景；卡片保留作者底色、渐变和透明度。

## 首次安装

1. 先导出自己的 UI 主题与自定义 CSS，保存现有外观。
2. 下载 [NVWA 液态玻璃 · 美化主题.json](install/NVWA%20液态玻璃%20·%20美化主题.json)，在“用户设置 → UI 主题”中导入，并在下拉框明确选中“NVWA 液态玻璃”。只导入不等于已经应用。
3. 选择一种方式安装扩展。

**方式 A：使用酒馆的扩展安装入口**

在“扩展 → 安装扩展”中填写：

```text
https://github.com/jjing8235-afk/NVWA-Liquid-Glass
```

**方式 B：使用酒馆助手安装脚本**

将 [NVWA 液态玻璃 · 酒馆助手安装脚本.json](install/NVWA%20液态玻璃%20·%20酒馆助手安装脚本.json) 导入酒馆助手全局脚本库，开启后按提示安装。脚本保留主题前置检查、安装确认与“检查更新”按钮。

## 常用设置

在“扩展 → NVWA 液态玻璃”中打开玻璃设置，也可使用折叠菜单里的外观工作台入口。

| 位置 | 可以调整什么 |
| --- | --- |
| 外观与材质 | 玻璃材质、弧度、深浅切换、壁纸与外观存档 |
| 界面布局 | 顶栏常用入口、输入区、楼层显示、悬浮球拖动与融合 |
| 阅读文字 | 四款文字风格、字号、行距、缩进与消息背景滤镜 |
| 高级与兼容 | 御风性能相关选项、棱光折射方式、环境适配与诊断 |

手机姿态高光开启后会尝试恢复使用；浏览器要求系统授权时仍需用户允许。关闭开关会停止相应监听。诊断导出不包含聊天正文、草稿、角色名、壁纸地址与账号配置。

## 兼容与验证

不要同时开启多份 NVWA 或其他整页美化扩展。配套主题不会替你关闭其他扩展，插件也不会自动清空自定义 CSS 或覆盖个人主题。

默认按浏览器能力选择渲染路径；需要减轻渲染负担时，可选择澄卿。当前测试版 iOS 的漾卿壁纸折射跟随边缘折射开关，说明见 [iOS 折射测试](IOS-REFRACTION-TEST.md)。

自绘卡片、iframe 与外部浮窗保留作者样式；跨域和沙盒隔离继续生效。预设 / 记忆适配保留显示边界，不接管业务脚本、提示词、数据与保存逻辑。

测试基线通过 23 项离线回归、52 组反光 RGBA 对照与 4 组 Worker PNG 解码像素对照；正式包另行检查版本、安装资源、源码一致性与实际宿主加载。240 层 / 4 倍 CPU 降速的桌面模拟显示魔杖首开和快捷回复开关有改善，**不代表实际手机 FPS、INP 或所有卡片的兼容保证**。首次加载、复杂卡片和宿主扩展仍可能带来额外开销。

## 退出与恢复

先关闭扩展的美化开关；需要卸载时，在扩展管理中停用或卸载，再切回自己的主题与 CSS 备份。切换到测试版或另一份安装前，先停用当前版本，避免重复加载。

配套主题的导入、删除与更新由用户手动完成。请保留个人主题备份，不删除其他主题。
