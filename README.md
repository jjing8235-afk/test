# NVWA 液态玻璃 · 独立外观工作台

**测试版本：1.4.5-test.13（2026-11-09）**。在 1.4.4-local.9 之后合入澄卿、四款阅读风格、外观存档、设置收整，并做了一轮手机专项：键盘、触摸区域、阅读位置、流式输出流畅度。

**手机专项（test.13）**
- 键盘：iOS Safari 和不会自动让出键盘高度的 WebView 上，输入框会贴在键盘上沿；安卓 Chrome 由浏览器自己缩小页面，扩展不重复补偿。双指放大不会被当成键盘。键盘打开时悬浮小球暂时隐藏。
- 阅读位置：往上翻旧消息时，输入框变高、键盘开合、转屏或上方图片加载完，正在读的那条消息都留在原位；停在底部时仍交给酒馆自动滚动。
- 触摸区域：输入区 40px 的按钮外圈多给 2px 的透明点击范围，折叠菜单按钮、工作台关闭按钮、分类标签和开关都扩到 44px；图标本身大小不变。
- 流畅：思考小球不再每帧读取页面布局，改为每秒 30 帧；流式输出时最后一条消息的玻璃最多 250ms 重画一次，结束后立即补画；顶栏明暗采样在生成期间放宽到 1.2 秒一次。窗口尺寸变化合并成一帧处理，只改高度（键盘开合）时不再整页重画玻璃。4 倍 CPU 降速的手机模拟里，每次流式更新从约 288ms 降到约 191ms。
- 阅读页新增“正文行距”和“正文左右留白”滑杆，各带“跟随风格”复原按钮；只作用于普通正文。
- 工作台记住上次打开的分区和滚动位置（只在本次浏览会话内）。
- 字体细修：行首全角标点收紧、中英文自动间距、浅色心声更清楚、笺月心声用楷体、窄屏行距收紧。


从“菜单 → 玻璃设置”，或扩展页的“打开玻璃设置”进入独立工作台。外观与材质、界面布局、阅读文字、高级与兼容分为四区；果冻式开关支持键盘、明暗跟随当前界面、窄屏滚动与减少动态效果。原来的外观弹层已整合进工作台。

新增“澄卿 · 通用仿液态玻璃”：在“外观与材质 → 渲染方式”切换，替代原“仅模糊”。用基础 CSS 轻模糊、细亮边与柔和投影模拟质感，不构建 SVG 折射或轮廓反射贴图；输入框仍为空白高透、有字增加可读性。映卿 / 漾卿的选择与参数保留，切回自动适配可恢复。细节及参考来源见 [CSS-GLASS.md](CSS-GLASS.md)。

渲染命名与文字风格（2026-11-09）：自动适配显示为“随境”，轻量 CSS 材质显示为“澄卿”，内部 auto / blur 值不变。阅读页提供青瓷、栖暖（原经典橙光）、“笺月”（宋体优先、疏朗行距、月紫对白）与“晴笺”（清爽黑体、适度紧凑、蓝调对白）。栖暖保留 classic 存储值，用柔和琥珀高亮与正体心声替代旧橙光的斜体；四款按各自行距、段距留出停顿，原生引文使用细线，正文链接使用轻下划线。四款卡片同时展示叙事与对白字样，点选时使用各自的主题色，完整预览与普通正文同步；新风格优先使用设备已有字库，缺少时系统回退，不新增字体下载。字体与段距规则限定在既有 ilg-prose 普通正文标记上，不扩大到代码、自绘卡片或 iframe；外观存档继续支持保存、恢复、撤销和刷新保留。

顶栏外观图标单击按“白天 → 黑夜 → 自定义”循环，不再打开面板。自定义使用调色盘图标，优先恢复曾选过的自定义壁纸；首次未选自定义壁纸时保留当前背景，按壁纸适配，不主动弹出选择器。

两套材质在面板中命名为「映卿」（原版）与「漾卿」（Liquid Glass Web），使用独立 SVG 滤镜、贴图与参数。原版恢复 local.7 的折射几何（弧面、厚度、放大、折射率和色散），清透度与方向反光单独调整；仅修复仍完整匹配 local.8 预设的参数，保留手调组合。原版输入框在自定义壁纸上沿用低浓度底色，撤去旧 42% 黑底和 64% 白底。

Web 提供四套本项目适配预设：原感清透、轻薄、柔光、厚边。“原感清透”保留此前接受的 Web 效果；其余通过折射圈、强度、低模糊、细反光与投影区分。webPreset 独立保存；原版滑块不改变 Web，Web 切换也不重写原版折射。仓库核验仍是固定提交 3094add905e60ee5aeb45e806751beb94425dd73；上游无新增命名预设，这四套不是上游官方预设。

原版、Web 与悬浮球统一按真实轮廓法线绘制反光：拐角细亮、直边收弱、内侧柔和回亮，中央透明。光源保持固定，按钮按压时只短暂提亮接触附近的边缘，松开或取消即恢复；悬浮球反光随融合轮廓变化。贴图按尺寸缓存，鼠标移动与普通输入不重建反光贴图。鼠标移动不会追光。可在“外观与材质 → 光感”开启“手机姿态高光”，点击“授权 / 以当前握姿居中”：手机倾斜时，只让一层淡反光在弧边轻微变化；默认关闭，不会在加载时请求姿态权限。传感器没有响应、权限未获准或访问环境不支持时保持固定高光。姿态更新只改变两个 CSS 坐标，不重建折射或反光贴图。切后台、关闭模糊、关闭扩展或开启减少动态效果时暂停监听。空输入框保持高透，有字或 IME 预编辑时仅轻柔化中心，清空即恢复；折叠顶栏保持高透。减少动态效果时停用按压反光，继续关闭弹簧、缩放与过渡，输入框与图标容器不发生缩放或位移。

“高级与兼容 → 导出诊断”点击直接下载 UTF-8 TXT，包含版本、能力、当前材质与显示状态，排除聊天正文、未发送文本、角色名、壁纸地址和账号配置。

“我的外观”位于“外观与材质”页下部，首次加载先保留当前外观；“保存当前外观”更新这一份存档，“恢复已存外观”可找回材质、字色、文字排版、布局、小球和动态参数。恢复后可立即“撤销这次恢复”；继续手动调整或重新保存会结束这次撤销。存档随本扩展设置保存，刷新仍保留；宿主主题、壁纸、聊天正文、API 配置和历史备份不包含在外观存档中，恢复也不会自动请求姿态权限。

设置收整（2026-11-08）：打开先选映卿 / 漾卿；“外观切换”合并为自选、按时间、跟随系统，自选时才显示白天 / 黑夜 / 自定义壁纸，按时间时才显示白天时段。两种材质的预设分别以“映卿 · 弧度”和“漾卿 · 弧度”独立成组，放在外观切换之后，只显示当前材质的组；映卿七档、漾卿四档全部直接展开。手动参数仍可展开。“阅读文字 → 背景与可读性”集中管理聊天背景、卡片底色与面板加厚。“高级与兼容 → 基础效果与性能”保留折射开关、引擎、简洁图标、悬浮输入区及统一字体；小球吸边与融合位于“界面布局 → 拖动与融合”。仅整理入口，不迁移或强行覆盖既有偏好，也不改变材质内部标识和存档格式。

阅读细修：消息玻璃的反光比顶栏 / 输入区更轻，折叠菜单保持高透并减轻折射放大，深色普通文本与名字栏使用更短的默认字影。输入框增长时左右操作按钮靠近底部。短视口、横屏和多行输入已在 Edge 模拟尺寸下验证；真实手机键盘、候选栏与安全区仍需真机确认。

# NVWA 液态玻璃

**当前版本：1.4.4**。SillyTavern / TT 通用美化扩展：边缘折射玻璃、瓷白 / 墨黑深浅切换、悬浮输入区与角色目录。

本版合入 1.4.4-test.8 的已验证修正，新增聊天背景选择，改善滑块、勾选框与手机显示。已安装正式仓库的用户直接检查更新，重新载入后确认版本为 1.4.4。已有配套主题无需重新导入，现有美化参数继续保留。

作者：zytteell8698

## 1.4.4 更新内容

- **聊天背景可选模糊或透明玻璃**。模糊档保留原效果；透明档去掉消息磨砂和底色，保留圆角、玻璃边缘、折射与阴影。只影响消息外层，顶栏和输入框不变；切回模糊档恢复已存参数。
- **卡片消息沿用完整玻璃引擎**。独立背景层与普通消息使用同一套物理 / 旧版折射构建路径，卡片固定浮窗保留视口定位。
- **卡片不透明底沿用卡片自身颜色**。支持可识别的渐变和伪元素底色；无法取色的 iframe 与图片背景保留原有透明，不再强加默认深色或浅色矩形底。用户已确认此前 TT 原卡黑框消失。
- **手机操作与显示修正**。触屏滑块从圆点附近开始才拖动，点击轨道空白不改值；预设切换后进度条即时同步。修复勾选框勾色、电脑折叠菜单宽度与手机聊天右侧滚动条白缝。
- **正文两端对齐**可选，默认关闭；保留聊天字号与普通正文首行缩进设置。
- **复制卡片显示诊断**：便于定位卡片背景与内嵌页面问题，记录不包含聊天正文、角色名及链接地址；系统不支持自动复制时可手动复制。

验证分开记录：本机源码与隔离浏览器检查通过；用户已确认 TT 原卡黑框消失。桌面安卓身份模拟不能替代全部手机性能或所有卡片验收。iOS 默认兼容模糊，SVG 折射仍是默认关闭的实验。

## 安装顺序：先主题，后插件

### 1. 先备份旧主题

在「用户设置 → UI 主题」里导出当前主题，自己粘贴的自定义 CSS 也建议单独保存。
**配套主题将自定义 CSS 设为空，并调整配色、气泡、头像、阴影等 UI 参数。没有备份就不要直接覆盖自己精心调整的主题。**

### 2. 导入并选中配套主题

下载 [NVWA 液态玻璃 · 美化主题.json](install/NVWA%20液态玻璃%20·%20美化主题.json)。
在「用户设置 → UI 主题」右侧导入，然后在下拉框中明确选择「NVWA 液态玻璃」。
**只导入文件不等于所有设置已经应用，必须选中一次。**

主题只提供底座，不包含重复的插件 CSS、脚本或远程资源。减少动态效果的偏好不被主题覆盖。

### 3. 安装插件（二选一）

**方法 A：酒馆自带扩展安装**

扩展 → 安装扩展，粘贴：

```
https://github.com/jjing8235-afk/NVWA-Liquid-Glass
```

**方法 B：酒馆助手安装脚本**

导入 [NVWA 液态玻璃 · 酒馆助手安装脚本.json](install/NVWA%20液态玻璃%20·%20酒馆助手安装脚本.json) 到酒馆助手的全局脚本库，打开脚本开关并按提示安装。
尚未选中配套主题时，脚本只提示准备主题，不执行安装。装好后会刷新；按钮「检查更新」用于后续更新。

## 使用与冲突边界

- 首次运行会将瓷白、墨黑两张壁纸加入背景库；选其中一张可按时间自动换深浅。
- 设置位于「扩展 → NVWA 液态玻璃」。插件会显示主题未导入、未选中或关键选项改变的提示，但不会自动切主题或清空 CSS。
- 喜欢首行缩进时，在同一设置面板打开「普通正文首行缩进两个汉字」。默认关闭，只影响普通正文段落；列表、代码、引用块及自带样式面板不接管，也不修改聊天原文。
- 不要同时启用其他整页美化扩展。选择配套主题不能阻止另一扩展写入样式；本插件不会自动关闭其他扩展，也不修改角色卡或世界书内容。
- 默认按内核能力自动适配，无需勾选“是不是 TT”。ST Chromium 保留原路径；符合模糊及 SVG URL 语法门槛的安卓 WebView 自动尝试兼容折射。不满足条件时使用模糊降级；显示异常可选“环境适配 → 仅模糊”，该选择会保存。
- iOS 默认兼容模糊。独立 SVG 折射实验放在“玻璃细调参数”内，默认关闭；真实 iOS 折射仍待实机确认。详见 [iOS 测试说明](IOS-TESTING.md)。
- 玻璃细调参数默认折叠，减少手机滚动误触；收起不会改变已保存数值。
- 原生扩展列表、删除角色和新建聊天确认项显示清楚的勾选状态；不改删除、启停或保存逻辑。
- 卡内面板、可访问的消息 iframe，以及宿主核心区之外的独立浮层自动去掉文字阴影。按固定定位或弹窗/菜单语义识别，不依赖特定卡名或 ID，不增加开关。自绘卡片所在消息把玻璃画在独立背景层，保留完整材质并避开固定浮窗的定位边界；面板移除或美化停用后清理背景层。

## 第三方特色弹窗

酒馆原生通用弹窗保留外壳和原生控件适配，不补强制关闭按钮。第三方窗口不接管布局、交互或保存逻辑；对宿主核心区之外可见的固定定位或带弹窗语义的独立浮层，只自动清理文字阴影。关闭、重开或重新创建后会重新识别；关闭美化会撤去标记和运行时样式。

可访问的消息/浮层 iframe 支持加载、重载和嵌套前端。跨域或沙盒隔离的内容保持隔离，不改 iframe 源码。无语义的任意绝对定位容器、文字描边、图形滤镜或重复文本等重影来源不保证覆盖；未知组合仍需现场检查。

已确认兼容的例外：NVWA 预设面板与 NVWA 记忆界面保留专门的深浅色玻璃适配。仅匹配酒馆原生 Popup 内直接承载的 `#nvwa-panel` / `#nvwa-memory`；不扩展到其他记忆插件，不修改预设文件、提示词、记忆数据或保存逻辑。

## 验证与边界

本版运行代码与测试仓库 1.4.3-test.7 完全一致，仅正式名称、版本、地址与文档作发布整理，保留正式安装器与主题素材。发布前核对全部测试源码与保留文件，检查正式清单、语法和既有源码回归；测试阶段的浏览器证据沿用同一份运行代码。详细来源、检查及未测项见 [VALIDATION.json](VALIDATION.json)。

测试阶段通过 18 项源码检查、6 组界面/卡片浏览器套件、9 项性能/菜单/字号/开合回归及 Chromium、Windows WebKit 的 8 组首页/头像场景。桌面计数与模拟手机身份不等于真实手机性能；原安卓 TT 空列表原因、完整点击耗时与 iOS 真机折射仍待确认。首次数据读取和宿主重建列表仍有必要开销。

## 更新配套主题

SillyTavern 1.18 不允许导入同名主题。已装旧版时，先导出旧主题和自定义 CSS 作备份，切到另一主题，再手动删除旧的「NVWA 液态玻璃」，导入新版并在下拉框选中。
**不要删除自己的其他主题。** 插件不会自动删除、覆盖或更新主题文件。

## 退出与恢复

先关闭本插件的美化开关，或在扩展管理中停用并刷新，再导入、选择安装前导出的旧主题；必要时粘回单独备份的自定义 CSS。
新流程不在后台保存或恢复用户主题；旧版本曾留下的备份字段仍保留，但当前没有一键还原按钮。
