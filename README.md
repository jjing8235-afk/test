# 测试 · NVWA 液态玻璃

安卓 TT 兼容候选版 **1.4.2-tt.1**，基于现有 1.4.1。该仓库是独立的私有测试仓库，不修改原仓库。

## 下载

登录有权访问此仓库的 GitHub 账号后，使用 Code → Download ZIP，或访问：

https://github.com/jjing8235-afk/test/archive/refs/heads/main.zip

这是完整扩展文件包，不是酒馆助手脚本 JSON，也不是 APK。手机 TT 的本地导入入口尚未验证，不保证点击 ZIP 即可安装。私有仓库的匿名安装地址可能无法被 TT 访问；不要把 GitHub token 拼进下载链接。

## 使用

1. 使用已确认支持的扩展安装/更新方式替换原美化文件，保持同一份扩展，不同时启用两份。操作前备份当前扩展与设置。
2. 关闭旧的 0.1.0 / 0.1.1 诊断脚本。
3. 到扩展 → NVWA 液态玻璃，手动开启“安卓 TT / WebView 兼容折射”。默认关闭，只有设备验证通过后再开启。
4. 保持“边缘折射”开启，使用物理折射引擎；楼层胶囊、顶栏和输入框进入同一材质路径。配套主题未改，无需重新导入。
5. 异常时关闭兼容开关回退；关闭扩展并刷新可退出美化。恢复旧版请使用自己的原始备份。

## 改动

- 已验证的安卓 Chromium WebView 可通过手动兼容开关请求折射，不再因缺少 window.chrome 就永久拦截。仍要求标准模糊与 SVG URL 属性语法可用，不给 iOS / Firefox 强开。
- 物理折射模式统一撤去旧降级白亮边和内侧高光阴影，明确覆盖楼层胶囊。关闭兼容或折射时回退恢复。
- 设置沿用 iosLiquidGlass 命名空间；保留未知字段和原有备份。

## 验证边界

18 项源码隔离检查、14 项完整候选入口的隔离浏览器检查通过；另有原引擎缓存、弹窗边界、缩进回归。浏览器测试使用桌面 Edge 与模拟宿主，不是安卓真机。

用户已在之前诊断版上确认当前安卓 TT 可显示折射；本完整候选版的安装、楼层胶囊、长聊天和性能仍需真机验收。属性语法通过不代表真实渲染成功。
