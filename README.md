# NVWA 液态玻璃 · ST / TT 通用测试

版本 **1.4.3-test.1**。同一份扩展供 SillyTavern 浏览器、安卓 TT / Chromium WebView 和 iOS TT 使用；按内核能力选择路径，不要求用户勾选“是不是 TT”。本仓库仍是独立公开测试仓库，不修改正式 NVWA 仓库。

## 本次补齐独立悬浮窗

新增通用的独立浮层识别：在宿主核心区之外，按固定定位或 dialog / menu / listbox / popover 等语义寻找可见的悬浮内容；不依赖任何卡片名称、专用 ID 或脚本名。命中的窗口和可访问 iframe 自动去除文字阴影。关闭、重开、隐藏、移除及美化总开关变化都会重新处理或清理，不增加设置开关。

真实电脑酒馆只读检查确认：反馈窗口直接挂在 body 下，宿主全局星号规则给所有文本加了 2px 阴影，窗口的 filter / backdrop-filter 均为 none；消息区规则无法覆盖这一层。通用候选遍历已命中该窗口，但没有替换电脑上的旧版正式安装。新版在完整模块隔离宿主中的多种任意命名浮层通过验证，实际安装后的原卡画面仍待复测。

普通正文、顶栏、宿主主要布局不参与外部浮层扫描；不改窗口配色、字体、边框、投影或定位。没有弹窗语义且不使用固定定位的自定义容器，以及跨域 / 沙盒隔离的前端不保证覆盖；仍有重影时需要现场 DOM 证据，不通过清空全站文字样式兜底。

## 保留的自动去重影

卡内自绘面板、选项按钮和浏览器允许访问的消息 iframe 自动清除文字阴影；没有新增开关或设置字段。自绘面板/可见 iframe 所在消息自动撤去外层玻璃滤镜，避免二次合成使内容发虚；普通正文消息、顶栏和输入框仍按原逻辑显示玻璃。面板移除后恢复该消息的玻璃。

只改变运行时样式，不改卡片原始 HTML/JSON、iframe srcdoc、字体、配色、布局或边框投影。关闭美化总开关会恢复卡片原字影并移除注入的样式、监听和观察器。自绘面板本来写出的文字阴影也会自动去掉；没有对文字描边、图形滤镜或重复文本节点作强制处理。

同源消息 iframe 支持加载/重载、动态和嵌套前端。跨域与不含 allow-same-origin 的沙盒 iframe 保持隔离；不向它们发送消息、不请求额外权限，也不改无关 iframe；被识别为独立悬浮窗的可访问 iframe 同样处理。

## 保留的统一版功能

- 修复原生“删除角色”“新建聊天”确认项和扩展管理列表的勾选显示：选中蓝底白勾，未选中空框，禁用变淡。原生附加选项同样处理；未改删除或启停逻辑。
- 玻璃细调参数默认折叠。需要调整时点标题展开，收起不会改动已保存数值。iOS 折射实验放在其中。
- “环境适配”默认自动：保留 ST Chromium 的原路径，符合门槛的安卓 WebView 自动尝试兼容路径，iOS 默认兼容模糊。显示异常可选择“仅模糊”，该选择随原设置保存。
- 检测到同一文档内的可见固定定位悬浮内容时，暂时撤去所在消息的玻璃滤镜、位移和宿主裁切，关闭面板后恢复；其他消息、顶栏和输入框保留玻璃。原生弹窗/菜单去掉宿主文字光晕，原生通用弹窗增加可读底色。卡片文字字影由上述自动处理接管，边框和容器投影保留。

旧版安卓兼容勾选字段仍保留在设置中，但不再决定渲染路径；没有新版环境设置的用户升级后默认自动。有问题请选择“仅模糊”，无需清空参数或聊天。原折射引擎、素材和设置空间保持兼容。

## 自动适配的边界

识别内核不能唯一识别 TT 应用，也不能证明真实折射已经发生。自动路径仍受美化总开关、边缘折射开关、消息玻璃开关和宿主“关闭模糊”设置约束。

ST Chromium 保留原自动折射；安卓 Chromium WebView 需接受标准模糊及 SVG URL 语法才尝试兼容折射。不符合门槛的环境使用模糊回退。iOS 默认兼容模糊；如需试验，展开“玻璃细调参数”，手动打开“iOS WebKit SVG 折射实验”，对比画面后反馈。选择“仅模糊”会覆盖所有平台的折射请求，包括 iOS 实验；切回自动会恢复原先保存的实验选择。

恢复默认会回到自动适配，并关闭 iOS 实验，保留主题备份和未知设置。

## 裁切与模糊反馈的边界

已用隔离用例复现旧版消息玻璃使固定定位面板偏位、被其他消息玻璃覆盖的情况；新版可让该用例恢复到视口坐标，动态关闭后恢复消息玻璃。对可见固定定位 iframe 外壳也能识别；不进入 iframe 内修改内容。

用户截图中的角色卡原始源码尚未提供，所以不能把隔离用例通过视为该卡已经验收。卡内自设固定宽度、禁止换行、内部 overflow 裁切、iframe 自身尺寸或跨域内容仍需原卡/原前端代码定位，不能靠全局强制换行安全修好。

## 验证

发布记录见 VALIDATION.json：Windows Edge / WebKit 完整模块运行于隔离的 SillyTavern DOM/context，覆盖自动适配、手动回退、iOS 独立实验、消息开关、刷新、恢复默认、主题备份、原生弹窗和第三方边界。新增深浅色、390 / 1280 宽度的自动去重影、iframe 生命周期、普通正文保留及关闭还原检查，并补充跨域/嵌套 URL 来源检查；已有确认框、折叠、悬浮内容、勾选状态及物理引擎回归继续通过。
