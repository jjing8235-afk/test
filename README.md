**手机专项（test.13）**
- 键盘：iOS Safari 和不会自动让出键盘高度的 WebView 上，输入框会贴在键盘上沿；安卓 Chrome 由浏览器自己缩小页面，扩展不重复补偿。双指放大不会被当成键盘。键盘打开时悬浮小球暂时隐藏。
- 阅读位置：往上翻旧消息时，输入框变高、键盘开合、转屏或上方图片加载完，正在读的那条消息都留在原位；停在底部时仍交给酒馆自动滚动。
- 触摸区域：输入区 40px 的按钮外圈多给 2px 的透明点击范围，折叠菜单按钮、工作台关闭按钮、分类标签和开关都扩到 44px；图标本身大小不变。
- 流畅：思考小球不再每帧读取页面布局，改为每秒 30 帧；流式输出时最后一条消息的玻璃最多 250ms 重画一次，结束后立即补画；顶栏明暗采样在生成期间放宽到 1.2 秒一次。窗口尺寸变化合并成一帧处理，只改高度（键盘开合）时不再整页重画玻璃。4 倍 CPU 降速的手机模拟里，每次流式更新从约 288ms 降到约 191ms。
- 阅读页新增“正文行距”和“正文左右留白”滑杆，各带“跟随风格”复原按钮；只作用于普通正文。
- 工作台记住上次打开的分区和滚动位置（只在本次浏览会话内）。
- 字体细修：行首全角标点收紧、中英文自动间距、浅色心声更清楚、笺月心声用楷体、窄屏行距收紧。

## 1.4.4 更新内容

- **聊天背景可选柔光或透明玻璃**。柔光档使用可调的背景阅读滤镜；透明档去掉消息磨砂和底色，保留圆角、玻璃边缘、折射与阴影。切换时保留已存参数。
- **卡片消息沿用完整玻璃引擎**。独立背景层与普通消息使用同一套物理 / 旧版折射构建路径，卡片固定浮窗保留视口定位。
- **卡片按原样显示**。保留卡片作者设置的底色、渐变、伪元素与透明度，不再强加实色底；iframe 内部不改写。
- **手机操作与显示修正**。触屏滑块从圆点附近开始才拖动，点击轨道空白不改值；预设切换后进度条即时同步。修复勾选框勾色、电脑折叠菜单宽度与手机聊天右侧滚动条白缝。
- **正文两端对齐**可选，默认关闭；保留聊天字号与普通正文首行缩进设置。
- **复制卡片显示诊断**：便于定位卡片背景与内嵌页面问题，记录不包含聊天正文、角色名及链接地址；系统不支持自动复制时可手动复制。

验证分开记录：本机源码与隔离浏览器检查通过；用户已确认 TT 原卡黑框消失。桌面安卓身份模拟不能替代全部手机性能或所有卡片验收。iOS 默认兼容模糊，SVG 折射仍是默认关闭的实验。

## 使用与冲突边界

- 首次运行会将瓷白、墨黑两张壁纸加入背景库；选其中一张可按时间自动换深浅。
- 设置位于「扩展 → NVWA 液态玻璃」。插件会显示主题未导入、未选中或关键选项改变的提示，但不会自动切主题或清空 CSS。
- 喜欢首行缩进时，在同一设置面板打开「普通正文首行缩进两个汉字」。默认关闭，只影响普通正文段落；列表、代码、引用块及自带样式面板不接管，也不修改聊天原文。
- 不要同时启用其他整页美化扩展。选择配套主题不能阻止另一扩展写入样式；本插件不会自动关闭其他扩展，也不修改角色卡或世界书内容。
- 默认按内核能力自动适配，无需勾选“是不是 TT”。ST Chromium 保留原路径；符合模糊及 SVG URL 语法门槛的安卓 WebView 自动尝试兼容折射。不满足条件时使用模糊降级；显示异常可选“环境适配 → 仅模糊”，该选择会保存。
- iOS 默认兼容模糊。独立 SVG 折射实验放在“玻璃细调参数”内，默认关闭；真实 iOS 折射仍待实机确认。详见 [iOS 测试说明](IOS-TESTING.md)。
- 玻璃细调参数默认折叠，减少手机滚动误触；收起不会改变已保存数值。
- 原生扩展列表、删除角色和新建聊天确认项显示清楚的勾选状态；不改删除、启停或保存逻辑。
- 卡内面板、可访问的消息 iframe，以及宿主核心区之外的独立浮层自动去掉文字阴影。按固定定位或弹窗/菜单语义识别，不依赖特定卡名或 ID，不增加开关。自绘卡片所在消息把玻璃画在独立背景层，保留完整材质并避开固定浮窗的定位边界；面板移除或美化停用后清理背景层。

## 第三方特色弹窗

酒馆原生通用弹窗保留外壳和原生控件适配，不补强制关闭按钮。第三方窗口不接管布局、交互或保存逻辑；对宿主核心区之外可见的固定定位或带弹窗语义的独立浮层，只自动清理文字阴影。关闭、重开或重新创建后会重新识别；关闭美化会撤去标记和运行时样式。

可访问的消息/浮层 iframe 支持加载、重载和嵌套前端。跨域或沙盒隔离的内容保持隔离，不改 iframe 源码。无语义的任意绝对定位容器、文字描边、图形滤镜或重复文本等重影来源不保证覆盖；未知组合仍需现场检查。

已确认兼容的例外：NVWA 预设面板与 NVWA 记忆界面保留专门的深浅色玻璃适配。仅匹配酒馆原生 Popup 内直接承载的 `#nvwa-panel` / `#nvwa-memory`；不扩展到其他记忆插件，不修改预设文件、提示词、记忆数据或保存逻辑。

新流程不在后台保存或恢复用户主题；旧版本曾留下的备份字段仍保留，但当前没有一键还原按钮。
