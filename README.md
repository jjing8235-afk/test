# NVWA 液态玻璃 · TT 兼容测试

版本 **1.4.2-tt.2**。保留安卓 TT 版 1.4.2-tt.1 的兼容折射和楼层去白边修复，合入默认关闭的 iOS WebKit 实验。本仓库是独立的公开测试仓库，不修改正式 NVWA 仓库。

## 安装与更新

仓库安装地址：

https://github.com/jjing8235-afk/test

已从本仓库安装的用户：在 TT 扩展管理中检查更新，完成后重启或强制刷新，确认版本为 1.4.2-tt.2。

首次安装：备份当前 NVWA 参数、扩展及主题，停用其他来源的 NVWA，再通过 TT 支持的扩展仓库安装入口安装本仓库。只启用一份 NVWA；两份共享同一设置空间和运行标记。不把旧版诊断脚本和本包同时运行。

下载文件 ZIP：

https://github.com/jjing8235-afk/test/archive/refs/heads/main.zip

ZIP 是扩展文件，不是主题 JSON、酒馆助手脚本 JSON 或 TT 安装包。TT 的本地 ZIP 导入方式尚未验证；仓库安装框应填上方仓库地址。

已有 NVWA 配套主题无需重新导入；新环境需要配套主题时，请先导出原主题及自定义 CSS，再使用 install 里的主题。原“一键安装正式版”脚本不包含在本仓库。

## 安卓 TT

- 继续使用“安卓 TT / WebView 兼容折射”。旧版已开启的选择保留；新用户默认关闭，确认本设备支持后手动开启。
- 保留顶栏、输入框和楼层胶囊的物理折射路径与旧降级亮边撤除规则；原 glass2.js 引擎、参数、字体和素材未改。
- iOS 实验控件在安卓隐藏，即使错误触发也不能替代安卓开关。
- 异常时关闭安卓兼容开关即可回到模糊；恢复默认会把两个实验开关都关闭，保留主题备份和未知设置。

## iOS TT

- 默认使用清透模糊降级样式，去掉被本扩展跟踪玻璃的旧亮边，保留消息中央文字衬底。
- “iOS WebKit SVG 折射实验”默认关闭。打开主“边缘折射”后，再手动开此项进行对照。
- 尝试标准及 WebKit 前缀属性，SVG 资源使用非零尺寸容器。语法检测通过、滤镜节点存在或开关开启，均不代表真实背景折射已成功。
- 用“复制 iOS 测试记录”回传环境和开关信息，并补充 iOS/TT 版本、机型及浅深色开关前后录屏。失败时可直接关闭实验。
- iOS TT 的安装、真实折射、键盘/安全区及性能尚未实机验收。详见 IOS-TESTING.md。

## 验证

26 项源码隔离检查、6 个桌面浏览器环境变体的 65 项完整模块交互检查通过；设置、滤镜复用、弹窗边界、正文缩进回归通过。原安卓兼容分支经过保留与回归，新合并版仍应在实际设备检查显示。

浏览器测试使用 Windows 桌面 WebKit / Edge 和模拟 SillyTavern DOM/context，iPhone、iPad、Android 身份用于执行分支，不能代替真实系统内核、TT 安装与实际渲染。iOS 真机结论保持待确认。完整证据见 VALIDATION.json。
