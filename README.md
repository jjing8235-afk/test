# NVWA 液态玻璃 · ST / TT 通用测试

**当前测试版本：1.4.4-test.12（2026-11-04）**。本仓库的 main 提供当前完整测试快照。作者：zytteell8698。

本次以已验证的 1.4.4-local.5 替换旧测试版的文件内容，保留仓库历史。测试版与正式版分别维护；此仓库用于体验和反馈，不代表所有宿主版本均已验收。

## 本次内容

- 保留已确认的首页效果、日间 / 夜间 / 自定义壁纸入口与外观面板。
- 提供“暖墨 / 经典橙光”阅读风格，分别适配浅色和深色。暖墨采用暖黑正文与琥珀对话、珍珠白正文与杏色对话，加入克制的强调细节；经典保留原有白色 / 橙色搭配。
- 保留用户字号、字体和现有聊天背景选择；不新增正文白底、黑底或阅读包裹层，不重置聊天或角色卡。
- iOS 新增默认开启的“iOS 兼容玻璃”：以系统背景模糊、方向性边缘反光和轻投影表现顶栏、输入框与分组控件。无须打开 SVG 实验；关闭后回到基础模糊。
- 兼容酒馆“关闭模糊 / 关闭阴影”，识别 TauriTavern 明确的 iOS 平台标记；桌面和安卓保留原路径。
- 诊断明确区分兼容材质、CSS 语法支持和真实像素折射，不收集聊天正文、未发送输入或账号配置。

## 安装或更新

在 SillyTavern / TauriTavern 的扩展管理器使用此 Git 地址，分支选择 main：

```text
https://github.com/jjing8235-afk/test
```

已经从此测试仓库安装的用户，执行“检查更新 / 更新”，再重新载入页面，确认扩展清单或 iOS 诊断显示 **1.4.4-test.12**。升级 TT 应用本身不会自动更新扩展文件。

测试版与正式版请只启用一份。如果当前安装来源是正式仓库，它的“检查更新”仍跟随正式仓库；要体验本版，请使用上面的测试地址。更新不要求清空聊天、角色卡或重置美化参数。

首次安装如需配套主题，可使用 install/ 下的“NVWA 液态玻璃 · 美化主题.json”；先导出原主题和自定义 CSS，再导入并选中主题。已有主题无需为本次重新导入。

install/ 下另有酒馆助手测试安装脚本，默认关闭。它指向本测试仓库；只有用户已选中配套主题且确认安装才下载。脚本和主题是两种不同文件，不要相互导入。源码 ZIP 也不是主题文件。

## iPhone 先这样验

保持“iOS 兼容玻璃”开启、酒馆“关闭模糊”关闭，先不要开启 SVG 实验。浅色和深色各看一次顶栏和输入框，切换兼容玻璃比较边缘反光，再检查输入、横竖屏和键盘。完整步骤见 [IOS-TESTING.md](IOS-TESTING.md)。

兼容材质不做背景像素位移。CSS 接受 SVG URL 不等于 WebKit 实际执行背景折射。

## 已验证与待验证

完整扩展已在桌面无头 Edge 执行 9 组 iOS 身份 / 能力场景，覆盖明暗、非气泡、设置保存、模糊 / 阴影开关、SVG 隔离、iPad 桌面身份与异常输入；阅读风格另覆盖 390 / 1280 px 和两种明暗。ST 1.18.0 的本机页面已验证 local.5 加载与首页保留。

发布版本另外复查清单、JavaScript 语法、设置 / 安装包一致性及 iOS 分支诊断。详细证据边界见 [VALIDATION.json](VALIDATION.json)。

**尚未完成 iPhone 真机安装、Apple WebKit 视觉、键盘 / 安全区与长期性能验收。** 桌面模拟身份不等于手机实测，也不承诺所有 ST / TT 版本通用。

## 退出与恢复

在扩展管理器停用并重新载入；需要恢复原主题时，导入安装前的备份。插件不会自动删除或替换用户的其他主题。
